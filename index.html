Proper reference architecture

From signal sources to business action

The target architecture is not just a dashboard. It is a telemetry operating model that connects cloud infrastructure, data pipelines, data quality, AI activity, SIEM signals and business impact.

Sources
  • AWS services: S3, Glue, Lambda, Step Functions, EMR, Athena, Redshift
  • Data engines: Spark, dbt, Airflow, Kafka, databases
  • AI activity: agents, MCP servers, tool calls, model inputs
  • Security events: sensitive data access, IAM, audit logs
OTLP / APIs / logs / metrics / traces
Collection
  • OpenTelemetry Collector / Grafana Alloy
  • Elastic Agent, Fluent Bit, Beats, CloudWatch exporters
  • Custom probes for freshness, schema and lineage checks
  • DPE deployment hooks and infrastructure metadata
enrich · batch · route · normalise
DataObs intelligence layer
  • Four-pillar model: full-stack, pipeline, data, business
  • Ownership, SLA, environment and business service context
  • Freshness, quality, volume, schema and lineage correlation
  • AI token, tool usage and sensitive-data behaviour signals
index · analyse · detect
Platforms
  • Elastic and Kibana
  • OpenSearch and Dashboards
  • Grafana, Tempo, Loki, Mimir
  • CloudWatch, Datadog, SIEM and ITSM workflows
alert · report · escalate
